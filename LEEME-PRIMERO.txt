📋 SI ACABAS DE RECIBIR ESTE SISTEMA:

1. Asegúrate de tener:
   ✓ Windows 7 o superior
   ✓ Node.js instalado (https://nodejs.org)
   ✓ MySQL ejecutándose (WAMP o XAMPP)

2. Ejecuta en ORDEN:
   ① INSTALAR.bat           (espera 3-5 minutos)
   ② CREAR-ACCESO-DIRECTO.bat
   ③ Doble clic en el icono del escritorio

3. Inicia sesión:
   Usuario: admin
   Contraseña: admin123


═══════════════════════════════════════════════════════════════
  📂 ARCHIVOS PRINCIPALES
═══════════════════════════════════════════════════════════════

INSTALAR.bat
  → Instala el sistema y crea la base de datos
  → Ejecutar PRIMERO y solo UNA VEZ

CREAR-ACCESO-DIRECTO.bat
  → Crea un icono en el escritorio
  → Ejecutar DESPUÉS de instalar

APLICACION.bat
  → Abre el sistema como aplicación de escritorio
  → Alternativa al acceso directo

INICIAR.bat
  → Abre el sistema en el navegador
  → Útil para probar o preferencia personal


═══════════════════════════════════════════════════════════════
  ⚙️ CONFIGURACIÓN DE MYSQL
═══════════════════════════════════════════════════════════════

CONFIGURACIÓN POR DEFECTO (WAMP/XAMPP):
✓ Host: localhost
✓ Usuario: root
✓ Contraseña: (vacía)
✓ Puerto: 3306

SI TU MYSQL USA CONTRASEÑA:
1. Abre el archivo: .env
2. Busca la línea: DB_PASSWORD=
3. Escribe tu contraseña: DB_PASSWORD=tu_contraseña
4. Guarda y cierra
5. Vuelve a ejecutar INSTALAR.bat

═══════════════════════════════════════════════════════════════
  ❌ PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════

"Node.js no está instalado"
→ Descarga de: https://nodejs.org (versión LTS)
→ Instala y reinicia el instalador

"Error al crear la base de datos"
→ Verifica que MySQL esté ejecutándose
→ WAMP debe mostrar icono VERDE
→ XAMPP debe tener MySQL en "Start"

"Puerto 3000 en uso"
→ Cierra otras instancias del sistema
→ Reinicia tu computadora

"No se encuentra .env"
→ Ejecuta INSTALAR.bat de nuevo

"El acceso directo no funciona"
→ Ejecuta APLICACION.bat directamente


═══════════════════════════════════════════════════════════════
  🌐 ACCEDER DESDE CELULAR/TABLET
═══════════════════════════════════════════════════════════════

Si quieres usar el sistema desde otro dispositivo:

1. Ejecuta INICIAR.bat en la PC
2. Mira la IP que aparece en pantalla
   Ejemplo: http://192.168.1.81:3000
3. Abre esa dirección en el navegador del celular
4. Asegúrate de estar en la misma red WiFi
